# Gestión de Máquinas y Generación de Etiquetas
Proyecto local para administrar información de máquinas, incluyendo nombre, modelo, marca y fotos. Permite generar etiquetas con la información almacenada, todo en una aplicación de escritorio local.

- Registrar máquinas con:
  - Nombre
  - Modelo
  - Marca
  - Foto de la máquina
- Almacenar datos de manera local usando MongoDB.
- Generar etiquetas imprimibles con la información de cada máquina.
- Funciona completamente offline como aplicación de escritorio.
- Interfaz con formularios para agregar y editar máquinas.
  
## 💻 Tecnologías
- **Backend:** Node.js + Express
- **Base de datos:** MongoDB
- **Frontend:** HTML, CSS, JavaScript 
- **Empaquetado como app de escritorio:** Electron
